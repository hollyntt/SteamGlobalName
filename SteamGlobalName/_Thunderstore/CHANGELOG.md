# Changelog

All notable changes to SteamGlobalName will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-16

### Added

- Initial release of SteamGlobalName.
- Option to automatically fill the character nickname field with your Steam username.
- Option to replace in-game player global-name labels with Steam usernames.
- `Use Steam Name` configuration setting, with optional EasySettings integration.
